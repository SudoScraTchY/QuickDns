Built like a tool, not a tray app.

A console program with one job: change DNS fast, on the adapter you choose, without getting in your way.

Target any adapter

Pick Ethernet or Wi-Fi explicitly, or leave Auto to choose the adapter that is up with an IPv4 gateway. Your choice is remembered.

Boots in milliseconds

No framework, no sleeps, no startup scans. The dashboard is ready in about 130 ms, measured on the dev machine.

Update-proof list

Presets live in your user profile with a silent auto-backup and a self-healing store.

One muscle memory, two platforms

Same keys everywhere. QuickDNS picks the right mechanism per system, automatically:

WindowsWMI, applied through a scoped adapter query. Admin required.
LinuxNetworkManager (persistent), resolvectl, or resolv.conf fallback. Auto-detected.

Download

Self-contained single-file executables. No .NET install, no installer. Every zip ships with a SHA256 checksum file.

Windows

QuickDNS-win-x64.zipWindows 10/11, 64-bit
QuickDNS-win-x86.zip32-bit x86
QuickDNS-win-arm64.zipWindows on ARM

Linux

QuickDNS-linux-x64.zipglibc, x64
QuickDNS-linux-arm64.zipglibc, ARM64
QuickDNS-linux-arm.zipglibc, ARM32
QuickDNS-linux-musl-x64.zipAlpine, x64
QuickDNS-linux-musl-arm64.zipAlpine, ARM64

Unzip, run QuickDNS (or QuickDNS.exe). Changing DNS needs elevation: administrator on Windows, sudo on Linux. macOS is not supported yet, so no macOS builds are shipped. Building from source needs the .NET 11 SDK; see the README in the repository.

Usage

The dashboard answers to the keyboard. Scripts get flags. Esc cancels anything, anywhere.

↑ ↓Select a preset
EnterApply it to the target adapter
AChoose the target adapter, or Auto
C / E / DCreate, edit, delete presets
UClear DNS, back to automatic (DHCP)
X / IExport or import your preset list
RRefresh adapter and DNS state
QQuit
QuickDNS                        # launch the dashboard
QuickDNS --diagnostics           # read-only health report
QuickDNS --export [path]         # presets to portable JSON
QuickDNS --import <path>         # import, duplicates skipped
QuickDNS --version | --help

# presets live in your profile:
#   Windows  %APPDATA%\QuickDns\
#   Linux    ~/.config/QuickDns/
Every clean start refreshes a silent backup. If the store is ever damaged, it is quarantined and rebuilt from that backup automatically, so an update can never wipe your list.

Your DNS list survives everything.

Updates, reinstalls, even a corrupted database. Three independent safety nets, no configuration required.

Lives in your profile

Presets are stored per user, away from the executable. Installing a new version never touches them.

Backs itself up

Every clean start silently refreshes a JSON backup of your whole preset list.

Heals when broken

If the database is ever damaged, it is quarantined, a fresh one is created, and the backup is restored into it on the next start.
